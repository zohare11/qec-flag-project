# Phase 9 reference outputs

`phase9_smoke_summary.md` is the development smoke run.

`phase9_full_reference_summary.md` and `phase9_full_reference_results.json` were assembled from the five full-config families run in fresh Python processes with the same canonical family-specific seeds. This is equivalent to the recommended `run_phase9.py split` execution mode and avoids retaining the large exact-pair temporary arrays across families.

These files are reproducibility references, not substitutes for rerunning the experiment locally.
